# Aplicativo GNP

Aplicativo mobile desenvolvido em React Native como projeto acadêmico, com foco em apresentar informações e funcionalidades relacionadas ao GNP FIT.

## 📱 Sobre o projeto

O GNP FIT foi desenvolvido como um projeto acadêmico durante minha formação em **Análise e Desenvolvimento de Sistemas (ADS)**.

A proposta do projeto foi desenvolver uma aplicação mobile utilizando **React Native**, permitindo a criação de uma experiência de navegação otimizada para dispositivos Android.

O projeto também foi uma oportunidade para colocar em prática conceitos de desenvolvimento mobile, organização de componentes, navegação entre telas e integração com recursos nativos do dispositivo.

## 🚀 Funcionalidades

- Navegação entre diferentes telas do aplicativo
- Apresentação de informações sobre o GNP FIT
- Organização de conteúdo em diferentes seções
- Interface adaptada para dispositivos móveis
- Componentização das telas e elementos da aplicação

## 🛠️ Tecnologias utilizadas

- React Native
- Expo
- JavaScript
- React Navigation
- React Native Paper
- Expo Fonts
- AsyncStorage
- Axios

## 📱 Plataforma

Atualmente, o projeto está configurado para execução em:

- Android

## 💻 Como executar o projeto

### Pré-requisitos

- Node.js
- npm
- Android Studio
- Android SDK
- Emulador Android ou dispositivo físico

### Instalação

Clone o repositório:

```bash
git clone https://github.com/Pimentazx/aplicativo-gnp-.git
```

Entre na pasta do projeto:

```bash
cd aplicativo-gnp-
```
Instale as dependências:

```bash
npm install
```
Inicie o projeto com:

```bash
npx expo start
```
